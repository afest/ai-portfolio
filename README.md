# ai-portfolio

Лендинг-портфолио Павла Юнусова: AI-автоматизация — агенты, боты и интеграции для бизнеса. Страница — https://afest.github.io/ai-portfolio/

Три экрана: главная из трёх слайдов, проекты (коллаж из карточек) и разборы проектов — что было, что сделано и что вышло, с галереей кадров.

## Как сделано

- Смена слайда и кадров галереи — шейдер на three.js: следующий кадр растёт из превью в углу.
- Кривые и длительности сняты замером по кадрам видео, а не подобраны на глаз: смена слайда — `cubic-bezier(0.662, 0.031, 0.384, 0.919)` за 901 мс, открытие статьи — 852 мс, шаг прокрутки коллажа — 943 мс. Параметры лежат в `src/cases/*/effects.json`, эффекты — кубиками в `src/kit/`.
- Для окна уже 1024 px своя раскладка, движение то же. На телефоне нет наведения, поэтому карточка проекта в середине экрана получает тот же рост картинки из угла и перебор подписи.
- Кадры проектов: сцены сгенерированы моделью, интерфейсы — настоящие экраны проектов на демонстрационных данных; раскладки интерфейсов и схемы собраны кодом. Обработка — `scripts/prepare_images.py`.
- Код писал Claude Code. Постановка, проверка и правки — мои.

## Запуск

```
npm ci
npm run dev        # http://127.0.0.1:5186/ai-portfolio/
npm run build      # сборка в dist/
node scripts/shots.mjs shots 1440,768,390   # скриншоты экранов, ошибки консоли, горизонтальный скролл
```

Для `scripts/shots.mjs` нужен браузер Playwright: `npx playwright install chromium`.
